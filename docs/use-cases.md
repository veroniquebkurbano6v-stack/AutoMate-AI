# 使用场景：谁在用 AutoMate AI

AutoMate AI 服务的是**不便于直接操作智能手机**的人群。这里用多段真实演示场景，
讲清楚"谁遇到了什么困难，AutoMate AI 如何帮他们完成"。

完整演示视频见仓库 [demo/](../demo/) 目录（README 📺Demo 可内嵌播放）。

---

## 场景一：用淘宝点奶茶 —— 不熟悉复杂购物流程的张奶奶

> 📹 视频：[demo/03_taobao_order_milk_tea.mp4](../demo/03_taobao_order_milk_tea.mp4)

**用户**：张奶奶，68 岁，独居。会用手机接打电话、刷短视频，但**不会**在购物 App 里
完成"搜索 → 进店 → 选规格 → 加购物车"这套跨页流程。屏幕字小、按钮多，她经常点错。

**她只说了**："帮我在淘宝点杯奶茶，珍珠的，正常糖正常冰。"

**AutoMate AI 做了什么**（全程自主，用户无需操作）：
1. 决策模型识别意图为"操作任务"，调用 `list_apps` 确认淘宝已安装，`kb_read` 检索
   端侧知识库中"淘宝闪购点外卖"的 SOP
2. 追问确认：奶茶品类、甜度温度、执行方式（外卖配送）
3. 生成结构化 Plan，交给执行模型逐步执行
4. 执行模型通过视觉定位（GUI-Plus）+ 无障碍树双通道，完成：
   - 打开淘宝 → 进入闪购 → 搜索"蜜雪冰城" → 进店 → 搜索"珍珠奶茶"
   - `select_spec` 自动选择"正常糖·正常冰"规格 → 加入购物车
5. 到达知识库覆盖边界（已加购）后**停止**，向用户汇报"已加购，后续结算请手动确认"

**价值**：把 8+ 步跨页操作，压缩成一句话。张奶奶不用学流程，也不用看清每个按钮。

## 场景二：用微信给联系人发消息 —— 手部不便的李叔叔

> 📹 视频：[demo/01_wechat_send_message.mp4](../demo/01_wechat_send_message.mp4)

**用户**：李叔叔，55 岁，因中风导致右手精细操作困难，打字和精准点击手机屏幕很吃力。

**他只说了**："用微信把'今天下午三点老地方见'发给老张。"

**AutoMate AI 做了什么**：
1. 决策模型定位到微信联系人"老张"，确认发送内容
2. 执行模型自动打开微信 → 找到联系人 → 定位输入框 → `auto_input` 输入文本 →
   定位发送按钮点击
3. 完成后向用户确认发送结果

**价值**：从"找联系人 + 点输入框 + 逐个打字 + 找发送键"（对手部不便者极其困难），
压缩成一句话。**语音/文本一句话即可**，配合端侧知识库离线也能用。

## 场景三：用高德导航到目的地 —— 低视力的王阿姨

> 📹 视频：[demo/02_amap_navigate.mp4](../demo/02_amap_navigate.mp4)

**用户**：王阿姨，61 岁，低视力（弱视），看不清屏幕上的小字和小图标，导航 App
的路线查询对她来说几乎不可用。

**她只说了**："导航去最近的医院。"

**AutoMate AI 做了什么**：
1. 决策模型调用 `amap_nearby` 检索"附近医院"，返回结果后确认目标
2. 检索知识库中"高德导航"SOP，生成 Plan
3. 执行模型打开高德地图 → 定位搜索框 → 输入目的地 → 选择路线 → 启动导航
4. 导航路线在大屏幕上展示，王阿姨只需听导航语音

**价值**：低视力用户看不清地图 UI，但 AutoMate AI 能"替她看、替她点"，
她把"去某地"变成一句话即可。

## 场景四：用高德分享位置到微信 —— 跨 App 协作

> 📹 视频：[demo/04_amap_share_location_wechat.mp4](../demo/04_amap_share_location_wechat.mp4)

**用户**：想把"附近评分最高的一家店"的位置直接分享给微信联系人，需要跨"高德地图"和"微信"两个 App 协作操作。

**他/她只说了**："在高德地图上把评分最高的一家店的定位分享给微信联系人。"

**AutoMate AI 做了什么**：
1. 决策模型调用 `amap_search` 检索目标店铺，按评分排序定位"评分最高"的那家
2. 打开高德地图 → 定位该店铺 → 触发"分享" → 选择微信联系人 → 发送定位
3. 跨 App 接力完成，全程无需用户手动切换 App

**价值**：跨 App 的"查→选→分享"流程一句话完成，替用户省去在多个 App 间来回切换的繁琐操作。

## 共同价值

| 场景 | 一句话替代的难度 | 涉及技术能力 |
|------|----------------|-------------|
| 淘宝点奶茶 | 8+ 步跨页购物流程 | 决策路由 + 知识库 SOP + 视觉定位 + 规格选择 |
| 微信发消息 | 打字 + 精准点击 | 无障碍树 + auto_input + 联系定位 |
| 高德导航 | 看不清地图 UI | amap 工具链 + 知识库 + 导航启动 |
| 高德分享位置 | 跨 App 查→选→分享 | amap 检索 + 跨应用接力 + 分享调用 |

**多通道感知**是共同底座：低视力用户靠**视觉 + GUI-Plus**，读屏/无障碍用户靠**无障碍树**，
AutoMate AI 同时具备两条感知通道，总有一条能"看到"屏幕。

**隐私**：端侧知识库让 SOP 检索完全离线、数据不出手机，契合障碍人群对隐私的关切。
